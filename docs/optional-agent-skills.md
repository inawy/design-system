# Optional External Agent Skills

هذه مرشحات وليست اعتماديات عامة. لا تنسخها أو تثبتها في جميع مشاريع ناوي. تأكد أولًا أن المشروع يستخدم التقنية المعنية، وافحص ملفات المهارة الحالية وترخيصها والسكربتات والصلاحيات المطلوبة.

## Supabase

المصدر الرسمي: https://github.com/supabase/agent-skills

المهارتان الموثقتان حاليًا:
- supabase: قاعدة بيانات Supabase وAuth وStorage وRealtime وEdge Functions وCLI والترحيلات وتكاملات العملاء.
- supabase-postgres-best-practices: SQL وتصميم المخططات والأداء والفهارس والتزامن وإدارة الاتصالات وRLS.

التثبيت لمشروع اعتمد Supabase بالفعل:
- npx skills add supabase/agent-skills --skill supabase
- npx skills add supabase/agent-skills --skill supabase-postgres-best-practices

نسخة المصدر التي تمت مراجعتها لهذا الفهرس: c9be0e931b7930f7d02126d04774d904c381e7d7. راجع المستودع الحالي وملف الترخيص الخاص بكل مهارة قبل النسخ أو التحديث. وجود المهارة لا يعني السماح بإنشاء قاعدة بيانات بعيدة أو تفعيل Auth أو تعديل RLS أو تغيير ملكية بيانات المشروع.

## Expo

المصدر الرسمي: https://github.com/expo/skills

استخدم مجموعة Expo الرسمية فقط إذا اعتمد أحد منتجات ناوي Expo أو React Native. مهارات Expo الأساسية تختلف عن خدمات EAS المدفوعة؛ اختر مهارات الإطار المجانية فقط ما لم تتطلب مواصفات المنتج خدمة EAS فعلًا.

تعليمات التثبيت وقائمة المهارات تتغير؛ راجع README الرسمي قبل التثبيت: https://github.com/expo/skills#installation

نسخة المصدر التي تمت مراجعتها لهذا الفهرس: 05754e71d02abe0d2d7a2fb5259ccac41f5ea59c. لا يعتبر هذا الفهرس ضمانًا لاستمرار أسماء المهارات أو أوامر التثبيت في المصدر.

## سياسة التحديث

1. لا تسحب تحديثات upstream تلقائيًا إلى مشاريع المنتجات.
2. افحص commit المصدر وبيانات المهارة والترخيص والسكربتات واتصالات الشبكة.
3. قارن التحديث مع حقائق منتجات ناوي ومعايير الهندسة الحالية.
4. ثبّت revision التي تمت مراجعتها، وحدّث سجل المصادر وChangelog.
5. شغّل Governance Validator وراجع diff كاملًا قبل الدمج.
