# ADR 0005: Curated Shared Agent Skills

- Status: Accepted
- Date: 2026-10-31

## Context

تستخدم مشاريع ناوي وكلاء برمجة بالذكاء الاصطناعي عبر مستودعات متعددة. تكرار التعليمات في كل مشروع يؤدي إلى اختلافها، بينما تثبيت كل المهارات الخارجية يضيف ضوضاء وافتراضات تقنية ومخاطر ترخيص وسلسلة توريد غير ضرورية.

## Decision

1. الاحتفاظ بفهرس مركزي منتقى في هذا المستودع تحت .agents/skills.
2. الإبقاء على مهارات سير العمل الست، وإضافة مهارات مشتركة للتخزين المحلي وسلامة البيانات وRTL وPWA وتفاعلات الهاتف والخصوصية والأمان واختبار المتصفح ومراجعة الواجهات.
3. تضمين مراجع Vercel المختارة لأداء React وأنماط تركيب المكونات فقط. تثبيت commit المصدر، والحفاظ على ملفات المصدر والمرجع المجمع الأصليين، وتسجيل الترخيص والمصدر في سجل المصادر والإشعارات.
4. إبقاء مهارتي الاختبار ومراجعة الواجهة بصياغة مستقلة لناوي، مع الإشارة إلى المراجع الخارجية دون تضمين سكربتاتها أو نصوصها.
5. إبقاء Supabase وExpo اختياريتين. لا تثبتان إلا للمشاريع التي اعتمدت هذه التقنيات وبعد مراجعة المصدر والترخيص والأمان.
6. تحميل المهارات عند الحاجة فقط. لا تحمل المكتبة بالكامل لكل مهمة.
7. تظل حقائق المنتج وكود المشروع وسياسة الأمان واختبارات CI هي المرجع. المهارات إرشادات وليست حدًا أمنيًا ولا بديلًا عن المراجعة.

## Consequences

- تستطيع المشاريع الجديدة والقائمة تبنّي المهارات المرتبطة بها فقط.
- يمكن التحقق آليًا من ملفات المهارات وسجل مصادرها في CI.
- تتطلب التحديثات الخارجية تثبيت revision ومراجعة صريحة.
- لا يغيّر هذا القرار كود التشغيل أو اعتماديات أو إطار عمل أو قاعدة بيانات أو سلوك أي تطبيق.
