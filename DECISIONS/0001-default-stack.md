# ADR 0001: Default Web Stack

- **Status:** Accepted
- **Date:** 2026-10-31

## Context

تحتاج منتجات ناوي إلى نقطة بداية موحدة تناسب Vibe Coding، وتنتج كودًا يمكن اختباره وصيانته، دون فرض backend أو SSR على كل أداة شخصية.

## Decision

الاختيار الافتراضي للمشروعات الجديدة الملائمة هو:
- React + TypeScript + Vite.
- Tailwind CSS.
- Dexie + IndexedDB عندما يحتاج المنتج تخزينًا محليًا منظمًا.
- Zod للتحقق من البيانات.
- Vitest + Testing Library، وPlaywright لتدفقات E2E الحرجة.

Node 24 LTS وpnpm هي بيئة التشغيل وإدارة الحزم المرجعية عند اعتماد القالب. الإصدارات الدقيقة تسجل في القالب وتراجع دوريًا.

## Alternatives

- Next.js لكل المشاريع: مرفوض كافتراضي؛ يضيف SSR/server conventions دون حاجة في تطبيقات SPA البسيطة.
- Vanilla JS: لا يوفر مستوى الأنواع والهيكلة المرغوب للمشروعات الجديدة.
- Backend إلزامي: مرفوض؛ كثير من الأدوات الشخصية يمكن أن تبدأ محليًا.

## Consequences

- قالب مشترك أسهل في البدء والفحص.
- تبقى حرية اختيار SSR أو backend عندما يفرض المنتج ذلك.
- يجب حفظ lockfile في مستودع كل منتج.
- لا يعني القرار أن التطبيقات القديمة يجب ترحيلها تلقائيًا.
