# ADR 0003: Local-first Data Preference

- **Status:** Accepted as a product/architecture preference, not a universal implementation requirement
- **Date:** 2026-10-31

## Context

تفضل منتجات ناوي تقليل الاعتماد غير الضروري على الخدمات السحابية، وإبقاء بيانات المستخدم تحت سيطرته عندما تسمح وظيفة المنتج بذلك.

## Decision

- عند ملاءمة المنتج، اجعل التخزين المحلي مصدر التشغيل الأساسي.
- استخدم IndexedDB عبر Dexie للبيانات المنظمة في تطبيقات الويب.
- النسخ الاحتياطي والمزامنة خدمتان منفصلتان؛ لا تخلط بينهما.
- لا تضف Supabase أو Auth أو sync لمجرد توفرها.
- وثّق مكان البيانات ومسارات إرسالها وطرق التصدير والاستعادة لكل تطبيق.

## Alternatives

- Cloud-first لكل التطبيقات: غير مناسب كافتراضي لكل أداة شخصية.
- Local-only مطلقًا: ليس مناسبًا للمنتجات التي تتطلب مشاركة أو تعاونًا أو مزامنة متعددة الأجهزة.

## Consequences

- يجب تصميم migrations وbackup/import ومعالجة التعارضات عند الحاجة.
- IndexedDB قد تتعرض للمسح أو الإخلاء؛ لا تعد بضمان حفظ مطلق.
- هذا قرار تفضيل معماري وليس إثباتًا أن بيانات أي تطبيق حالي لا تغادر الجهاز.
