# ADR 0002: Standard UI Icon Source

- **Status:** Accepted
- **Date:** 2026-10-31

## Context

تحتاج واجهات ناوي إلى لغة أيقونات احترافية ومتجانسة، مع أصول vector واضحة المصدر والترخيص. لا نريد Emoji أو أيقونات عشوائية تختلف من شاشة لأخرى.

## Decision

- المصدر الافتراضي: Google Material Symbols.
- النمط: Outlined.
- الصيغة: SVG محلي محفوظ في مستودع المنتج.
- في React/Vite: `vite-plugin-svgr` لاستيراد SVG عبر `?react`.
- احتفظ بمصدر كل أصل وإشعار Apache License 2.0.
- امنع Emoji وملصقات واتساب كأيقونات تحكم أو تنقل أو حالات.

## Alternatives

- Emoji: مرفوض بسبب اختلاف الشكل بين الأنظمة وعدم الاتساق البصري.
- تجميع مكتبات متعددة: مرفوض كافتراضي بسبب تفاوت stroke/size/style.
- Lucide كخيار افتراضي: ليس معتمدًا؛ يمكن الاستثناء بقرار موثق إذا فرضه منتج أو مكون خارجي.

## Consequences

- أسلوب أيقونات ثابت.
- مسؤولية اختيار أسماء الأيقونات وحفظ الأصول والإسناد داخل كل تطبيق.
- إذا لم يوجد رمز واضح، النص أفضل من رمز مربك.
