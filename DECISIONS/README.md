# Architecture Decision Records

يسجل هذا المجلد القرارات طويلة الأثر التي تؤثر في أكثر من منتج أو في معيار ناوي المشترك.

## متى نكتب ADR؟

- اختيار أو تغيير framework أو runtime أو قاعدة بيانات.
- تغيير مصدر أيقونات أو خطوط أو هوية مشتركة.
- قرار يتعلق بتخزين البيانات أو الخصوصية أو المزامنة.
- إضافة dependency محورية.
- استثناء معماري طويل الأجل.

## قالب القرار

- **Status:** Proposed / Accepted / Superseded / Rejected
- **Date:**
- **Context:** المشكلة والقيود.
- **Decision:** الاختيار.
- **Alternatives:** الخيارات التي تمت دراستها.
- **Consequences:** المنافع والتكاليف والمخاطر.
- **Evidence:** روابط الكود أو التوثيق أو الاختبارات.

لا تعدّل ADR مقبولًا لإخفاء تاريخه؛ أنشئ ADR جديدًا يشير إلى القرار السابق عندما تستبدله.
