# Layout & Spacing — التخطيط والمسافات

## مبادئ التخطيط

- صمم للمحتوى أولًا ثم رتب المساحة حوله.
- حافظ على تسلسل بصري واضح ونقاط تركيز قليلة.
- لا تملأ المساحات الفارغة بعناصر زخرفية.
- اجعل عرض القراءة مريحًا، خصوصًا في الشاشات الكبيرة.
- لا تفترض أن كل منتج يحتاج sidebar أو dashboard.

## نظام المسافات المقترح

شبكة أساسية بوحدة 4px:

| Token | القيمة |
|---|---:|
| space-1 | 4px |
| space-2 | 8px |
| space-3 | 12px |
| space-4 | 16px |
| space-5 | 20px |
| space-6 | 24px |
| space-8 | 32px |
| space-10 | 40px |
| space-12 | 48px |
| space-16 | 64px |

القيم مقترحة ويمكن توسيعها عند الحاجة، لكن تجنب القيم العشوائية المتكررة.

## الحواف والزوايا المقترحة

- Small: 8px.
- Medium: 12px.
- Large: 16px.
- Pill: 999px للأزرار أو الشرائح التي تحتاج شكلًا كبسوليًا.
- لا تجعل كل عنصر دائريًا؛ استخدم الشكل لخدمة التسلسل.

## RTL/LTR

استخدم الخصائص المنطقية:
- `margin-inline` بدل `margin-left/right`.
- `padding-inline` بدل `padding-left/right`.
- `inset-inline-start/end` بدل `left/right`.
- `text-align: start/end` بدل فرض اتجاه واحد.

اترك الأيقونات ذات الاتجاه الدلالي (مثل رجوع/تقدم) تتبع اتجاه اللغة عند الحاجة، لكن لا تعكس الرموز غير الاتجاهية مثل البحث أو الإعدادات.

## الاستجابة

- ابدأ بالهاتف عندما يكون المنتج موجهًا للاستخدام الشخصي المحمول.
- تجنب تثبيت ارتفاعات الحاويات التي تقص النص.
- استخدم قياسات مرنة مثل %, minmax, clamp, max-width.
- اختبر 320px على الأقل، ثم نقاط التحول التي يفرضها المحتوى لا أسماء الأجهزة.
- راعِ safe areas في الهواتف.
- لا تجعل التمرير الأفقي حلًا افتراضيًا لمحتوى يمكن ترتيبه عموديًا.
