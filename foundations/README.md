# Foundations — الأساسيات

الأساسيات هي اللغة المشتركة التي تُبنى عليها واجهات منتجات ناوي.

- [العلامة التجارية](brand.md): الاسم، الشخصية، الشعار، والنبرة.
- [الألوان](color.md): اللون الأساسي، الألوان الدلالية، والثيمات.
- [الخطوط](typography.md): الخطوط والتدرج الطباعي.
- [التخطيط والمسافات](layout-and-spacing.md): الشبكات، القياسات، والحواف.
- [الحركة وإمكانية الوصول](motion-and-accessibility.md): الحركة، التركيز، التباين، والتفاعل.

**تنبيه:** أي قيمة موسومة Proposed هي نقطة بداية عملية وليست قرارًا نهائيًا قبل اختبارها واعتمادها.
